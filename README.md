## ✨ Overview

Tempo is a productivity app built specifically for college and university students. Unlike generic task managers or calendar apps, Tempo understands academic workflows—from class schedules and prerequisite tracking to assignment deadlines, project collaboration, and tuition reminders.

Designed with an offline-first philosophy, Tempo keeps your data private and accessible even without an internet connection.
